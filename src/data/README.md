# src/data — כל התוכן של האתר

התוכן הוצא מדשבורד "China Family Trip 2027" בגרסה של 27.11.2026, עדכון שלישי בצהריים, באמצעות `tools/dashboard/`.
בבדיקה אוטומטית בנינו מחדש את נתוני הדשבורד מהקבצים האלה, והתוצאה זהה לדשבורד בכל ערך.

| קובץ | מה יש בו |
|---|---|
| `cities.json` | 7 ערים: שם באנגלית ובסינית, מיקום, צבע, מזג אוויר, אזור לינה, רחוב ראשי, חובה לראות ומרחקים |
| `places.json` | 54 מקומות, כלומר כרטיסי "יעדים" לכל עיר |
| `practical.json` | מידע מעשי מאומת: שעות, כרטיסים, מקור ותאריך בדיקה (26 מקומות) |
| `hotels.json` | 63 מלונות לפי עיר ורמה: budget (חסכוני), recommended (מומלץ), luxury (פינוק) |
| `hotel-lookups.json` | מיקומים מאומתים, שמות בסינית ומזהי Trip.com למלונות |
| `dayplans.json` | תוכניות יום אחרי יום: 27 ימים ו-79 תחנות |
| `day-routes.json` | מסלולי Google Maps לכל יום |
| `routes.json` | 5 המסלולים (A–E) |
| `transport.json` | 14 מעברים בין ערים, טבלת זמנים בין כל זוג ערים, וסוגי תחבורה |
| `images.json` | 81 תמונות (הקבצים עצמם ב-`public/img/`). ל-25 יש שם צלם ורישיון. ל-51 יש רק שם קובץ ב-Wikimedia Commons, בלי צלם ורישיון. ל-5 המקור לא רשום (sh1, ckg1, zjj1, gl1, ckg_liziba). צריך להשלים לפני פרסום ציבורי |
| `holidays.json` | 22 חגים בסין ובישראל ב-2027 |
| `settings.json` | הגדרות כלליות: סדר הערים, שער מטבע, קטגוריות ותוויות |
| `prep.he.html` | עמוד "הכנות", כפי שהוא בדשבורד (בעברית) |
| `map-china.svg` | מפת סין מהדשבורד |

## תרגום
כל טקסט בעברית שמור כך: `{"he": "...", "en": null}`. הערך `null` מסמן טקסט שעוד מחכה לתרגום לאנגלית.
שמות מקומות ומלונות כבר כתובים באנגלית ובסינית, ולכן לא צריך לתרגם אותם.

## מה לא נמצא כאן
- **פוסטים מ-RedNote:** הם לא שמורים כאן, כי התיקייה ציבורית. המקור הוא מסמכי המחקר בפרויקט ב-Claude. באתר הציבורי יופיע רק סיכום במילים שלנו, עם קישור לפוסט המקורי.
- **סימונים אישיים** (הזמנות, "שמור", הערות): הם נשמרים בחשבון Claude של הדשבורד, ויגיעו לאתר בשלב "הטיול שלי".
